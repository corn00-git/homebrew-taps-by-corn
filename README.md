# Corn00-git Taps-by-corn

## How do I install these formulae?

`brew install corn00-git/taps-by-corn/<formula>`

Or `brew tap corn00-git/taps-by-corn` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "corn00-git/taps-by-corn"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
